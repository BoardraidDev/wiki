# Getting started

BoardRaid is a task competition mod for Minecraft Java Edition 1.16.1. Install the client, then enter ranked, casual or custom play from the game.
## First launch
1. Get the official pack from [Downloads](https://boardraid.cn/en/download) and import it into Prism. Keep an unchanged instance for troubleshooting.
2. Sign into a Microsoft account that owns Minecraft Java Edition. Never share authentication tokens.
3. Launch Minecraft, select BoardRaid on the title screen and complete the client checks.
4. Try a solo custom room before joining a match.
## Reading order
Read Installation and Troubleshooting first, then Main game and Races. Individual goals are listed in the [task directory](https://boardraid.cn/en/tasks).
## Scope
This handbook targets stable 0.5.5. Development and experience-server features may differ. Room settings and the official rules take precedence.
