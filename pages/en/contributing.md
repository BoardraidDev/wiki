# Contributing and versions

## Edit the Wiki
Edit the relevant pages/zh and pages/en articles in the [Wiki repository](https://github.com/BoardraidDev/wiki). Submit a pull request with reasons, sources and applicable version.
## Editorial policy
Write original explanations; do not copy third-party prose or screenshots. Give source links, dates and applicable versions.
Write original explanations. Do not copy prose or screenshots from other projects. Link sources with access dates and distinguish facts, advice and unverified behavior.
## Versions
The [releases repository](https://github.com/BoardraidDev/releases) indexes stable versions and official downloads. Stable 0.5.5 is the baseline here. Documentation updates do not publish a client. Submit community PRs directly to this repository's master branch for owner review; private source release workflows do not apply.
## API
See [API docs](https://github.com/BoardraidDev/api-docs) for public read-only contracts. Never publish game authentication, internal controls or credentials in examples.

## Translation contributions
Edit an existing language or add a draft in [translation](https://github.com/BoardraidDev/translation). Preserve i18n keys and placeholders and submit a PR directly.
