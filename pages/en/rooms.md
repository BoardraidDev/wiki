# Custom rooms

## Create and join
Create a custom room or join with a room code. Share codes only with intended participants. Choose the player count and mode before creation; some settings lock afterwards.
## Before starting
Check participants, compatible client versions and room rules before the host starts. Solo practice does not use two-player voting.
## Multiplayer scope
Shared components do not mean identical drafting, results or supported modes. Fixes still being verified on release are not automatically part of stable play.
## Disconnects
Restore your connection and use the original account to reconnect. Read withdrawal prompts before voluntarily leaving.
