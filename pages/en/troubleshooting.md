# Troubleshooting

## Startup failure
Save the launch error. Check Minecraft 1.16.1, Fabric, API dependencies and duplicate BoardRaid jars. Diagnose Java and graphics errors before adding JVM flags.
## Client checks
Read the reported mod and version. Reproduce with an unchanged official instance. Filenames alone do not prove admission; do not bypass the checks.
## Matchmaking and reconnects
Verify the intended environment and client version. Reconnect with the same Microsoft account. Preserve logs for persistent black screens or stale match state.
## FPS and window hotkeys
Compare the same world, view distance and window size. Separate FPS from network latency and check external-tool window detection and hotkey conflicts.
## Reporting
Use [Wiki issues](https://github.com/BoardraidDev/wiki/issues) for version, reproduction steps and expected versus actual behavior. Remove tokens, email, IP addresses, chat and personal paths from logs. Report vulnerabilities privately via SECURITY.md.
