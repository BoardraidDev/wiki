# 开始游玩

BoardRaid 是 Minecraft Java 版 1.16.1 的任务竞赛模组。先安装客户端，再从游戏内进入排位、休闲或自定义房间。
## 第一次进入
1. 在[下载页](https://boardraid.cn/download)取得官方整合包，使用 Prism 导入。保留一个未改动的实例，便于排查兼容性。
2. 在启动器登录拥有 Minecraft Java 版的微软账号。不要把登录令牌交给其他玩家或第三方网站。
3. 启动游戏，在标题界面选择 BoardRaid 入口，完成客户端自检。
4. 先用单人自定义房熟悉卡板、选牌与按键；准备好后再匹配。
## 阅读顺序
安装遇到问题看「Prism 安装」与「故障排查」；进入游戏后看「主玩法」与「竞赛玩法」。具体任务见官网[任务目录](https://boardraid.cn/tasks)。
## 文档适用范围
本手册基于正式版 0.5.5 和现有源码核对。体验服与开发分支可能先出现新功能；未确认发布的行为不能当作正式规则。对局界面的房规和正式规则页优先。
