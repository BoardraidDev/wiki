# 贡献与版本

## 修改 Wiki
打开[公开 Wiki 仓库](https://github.com/BoardraidDev/wiki)，编辑 pages/zh 下相应文章，并同步 pages/en。提交 Pull Request，说明修改缘由、来源与适用版本；维护者审阅后合并。
## 内容要求
用自己的话解释玩家操作。不要直接搬运 Minecraft Wiki、MCSR Ranked、Draftout 或其他作者的正文与截图。引用外部资料时给出原始链接和查阅日期，并区分事实、建议与尚未验证的行为。
## 版本入口
[releases 仓库](https://github.com/BoardraidDev/releases)记录正式版本和官网入口。0.5.5 是本次整理核对的正式版本；修改文档不代表发布新客户端。正式版只从 master 的验证产物发布，release 是体验服验证分支。
## API 开发
在[API 文档仓库](https://github.com/BoardraidDev/api-docs)查看公开只读接口与 OpenAPI 文件。不要将游戏认证、内部控制接口或服务器密钥写入示例。
