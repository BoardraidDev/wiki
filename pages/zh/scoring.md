# 排位积分制度

公开积分用于个人资料、段位与榜单；匹配还维护独立的隐藏实力评估。两者不是同一个数，不能用双方公开分差直接倒推本局应加多少分。休闲与私人房间不会因为采用排位卡板或种子而计分。

## 初始值与结果

| 情况 | 公开积分结果 |
| --- | --- |
| 新账号 | 初始 1000 分 |
| 正常排位获胜 | 加分，单局最低 +2 |
| 排位失败 | 公开分不扣减 |
| 双方达成平局 | 双方均不加不减 |
| 对手放弃、离开或掉线形成的胜局 | 胜方仍按胜局结算 |
| 休闲、自定义与练习 | 不计排位积分 |

## 胜局加分怎样计算

| 对手隐藏实力相对自己 | 基础档位 | 随机微调后、裁剪前 |
| --- | --- | --- |
| 低至少 120 | 12 | 11–13 |
| 差距在上述两档之间 | 20 | 19–21 |
| 高至少 120 | 32 | 31–33 |

基础档位叠加 −1、0 或 +1 的微调，再由与平滑隐藏实力相关的软上限裁剪，最后应用胜局最低 +2。因而实际结果可能低于基础档位，正常胜局公开加分范围为 +2 至 +33；不能把基础 20 误认为每胜固定加 20。

## 隐藏实力和公开分的区别

隐藏实力会依据胜负和对手水平更新，并用于后续匹配与公开加分约束。公开分失败不扣，并不代表隐藏实力也不变；也不能通过公开榜单查询到其他玩家的隐藏数值。请以结算回包和战绩为准，不以旧客户端提示或过时攻略推算。

## 不要把未启用策略写成正式惩罚

当前实现关闭了重复对手衰减、每日上限与每周重复对手上限这一组反刷分计分开关，因此不应宣称「第几次遇到同一人就一定零分」。这不允许串通比赛、作弊或滥用匹配；行为处罚依官方规则处理，且未来调整需以公告为准。
