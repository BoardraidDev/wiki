# 故障排查

## 无法启动
先保存启动器的完整错误信息，检查 Minecraft 1.16.1、Fabric 和 API 依赖。确认 mods 中只有一个 BoardRaid jar。遇到 Java 或显卡报错时先定位对应条目，不盲目追加其他模组教程的 JVM 参数。
## 自检不通过
读取客户端指出的具体模组、版本或兼容问题，先在未修改的官方实例复现。不要根据文件名判断模组已获准，也不要绕过自检。
## 匹配或重连异常
确认正在连接正式服还是体验服，客户端版本是否对应。网络恢复后使用同一微软账号重连。持续黑屏或状态残留时保留日志，说明发生在加载、选牌、比赛还是结算阶段。
## 帧率低或窗口快捷键失效
先比较相同世界、视距和窗口大小，区分帧率下降与网络延迟。检查外部工具是否识别当前游戏窗口、快捷键是否冲突；不要把关闭安全检查当作优化办法。
## 提交问题
在[Wiki 问题入口](https://github.com/BoardraidDev/wiki/issues)提供系统、客户端版本、复现步骤、期望与实际结果。日志先移除 Token、邮箱、IP、聊天与个人路径；安全漏洞不要发公开 Issue，请看组织 SECURITY.md。
