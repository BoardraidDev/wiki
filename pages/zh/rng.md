# RNG 统一与战利品调整

RNG 指随机结果。BoardRaid 对受支持的比赛事件使用可复现的随机子流，并对部分稀有掉落加入减少极端连空的策略；它不是把所有原版随机关闭，也不是承诺双方在同一秒获得相同物品。

## 统一的是事件顺序，不是操作时钟

随机序列由世界种子、事件组、附魔档位与该组的消费位置共同决定。同一种上下文里，双方第 N 次有效尝试可得到可复现结果；不同资源和子事件分流，避免挖另一种方块就扰动目标的随机数。需要位置锚点的空间事件还会包含各自位置条件。

分组并不总等于一种实体：实现可让不同来源的同类资源共享一组。若两人击杀顺序、有效附魔、工具条件或已消费次数不同，眼前一次结果仍可能不同；不能仅凭「同一只怪没掉一样」判定同步失效。

## 接管的主要范围

| 系统 | 处理方式 |
| --- | --- |
| 资源掉落 | 沙砾燧石、烈焰棒、末影珍珠、凋零骷髅头等按目标与附魔档处理 |
| 基础资源组 | 皮革、骨头、箭等采用对应资源模型；概率与数量分开处理 |
| 交互事件 | 受支持的驯服、末影之眼、堆肥、村民交易与装备相关事件使用专属子流 |
| 猪灵交易 | 保留独立的交易表与额外加成随机流，不套用其他平台的交易次数保证 |
| 结构箱子 | 按箱子自身战利品种子生成；指定箱表再进行下述调整 |

## 软保底和硬保底怎样理解

适用目标会记录连续失败次数：前段使用标定后的初始概率，连空达到阈值后提高成功率，到硬上限则下一次必成；成功后该目标、该附魔档的失败计数归零。参数按原版对应附魔档的概率标定，目的是缩短极端连空，同时保持模型的长期平均，不应把初始概率误读为整体掉率。

| 示例：未附魔档 | 原版至少一次掉落概率基准 | 连续失败上限 | 下一次保证 |
| --- | --- | --- | --- |
| 沙砾 → 燧石 | 10% | 19 次 | 第 20 次有效尝试 |
| 烈焰人 → 烈焰棒 | 50% | 3 次 | 第 4 次有效尝试 |
| 末影人 → 珍珠 | 50% | 3 次 | 第 4 次有效尝试 |

「有效尝试」须满足该事件的原版上下文。精准采集、剪刀、爆炸与不符合掉落条件的击杀不能一概计入同一保底；时运与抢夺按各自档位处理，不能用零附魔计数推算所有工具。数量随机与是否掉落的判定也是不同子流。

## 箱子战利品有哪些变化

| 箱表 / 来源 | 正式实现的调整 |
| --- | --- |
| 沉船补给箱 | 火药总量拉入 5–11；原本无 TNT 时有 50% 机会补 1–2，已有 TNT 总量最多 2 |
| 沙漠神殿箱 | 铁不足时补至抽取的 1–2；火药不足时补至抽取的 2–4 |
| 丛林神殿箱 | 铁至少 4；腐肉不足时补至抽取的 2–4 |
| 村庄武器匠箱 | 针叶林 / 雪地按箱子群系判定至少 5 铁；其他至少 7 铁 |
| 村庄工具匠 / 盔甲匠箱 | 至少 7 铁 |
| 堡垒遗迹箱 | 使用原版箱表，不额外保底注入黑曜石 |
| 铁傀儡掉铁 | 适用对局世界中调整到 4–5 铁 |

除明确写了上限的沉船物品外，「补至」不是追加同样数量，也不是削减原版已经更高的数量。调整只处理指定表，补物需有可用槽位；不是所有叫「宝箱」的容器都套一张统一表。普通箱调整按每箱一次处理，不会每次打开都重新发奖。

## 保存、重连、重置与生效边界

受管理的随机状态随世界保存恢复，正常重连不是重新抽一套运气。个人重置世界是重新创建同种世界，序列按该新世界的起点重新消费；不改变对手世界，也不抹掉已完成的卡板目标。普通存档、模组自定义实体或未受支持的上下文不会因这段说明就自动获得同样保证。

> 共享 RNG、箱表调整与铁傀儡保底有各自的世界准入条件。主玩法对局是主要适用范围，Most% 另有共享事件接入；不要推断两种竞赛或任意原版存档都启用了整套改动。
